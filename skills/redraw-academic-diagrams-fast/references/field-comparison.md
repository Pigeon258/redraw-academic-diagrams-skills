# Field Comparison

Compare this Skill with `redraw-academic-diagrams` only on real user tasks. Do not create extra diagrams solely to improve a score.

## Record

- anonymized task ID and diagram class;
- selected Skill and version;
- builder and PowerPoint postprocessing;
- start time and first-delivery time;
- practical and formal state;
- number of fixlist items;
- user self-edit minutes;
- AI feedback rounds and additional AI minutes;
- final acceptance;
- repeated or high-impact defect categories.

## Compare

Use:

- time to first useful PPTX;
- total time to accepted result;
- user effort;
- AI feedback effort;
- final technical and editing quality;
- repeated defect rate.

Do not compare raw elapsed time when toolchains, task complexity, network delays, or user response delays differ without recording those confounders.

## Decision

After several real tasks, choose among:

- keep both Skills;
- merge them as delivery modes;
- make the fast Skill the default;
- retire the fast Skill;
- revise only a repeated, transferable rule.

Do not change a Skill from one isolated easy-to-fix issue.
