# Synthetic example

`synthetic-reference.svg` is an original, task-agnostic diagram used only to demonstrate an appropriate input class.

An editable redraw should provide:

- one PowerPoint slide;
- native editable title and labels;
- three semantic module groups;
- two single native relationship arrows;
- independent containers and text;
- no retained background reference image.

The example is not a benchmark and contains no expected timing score.
